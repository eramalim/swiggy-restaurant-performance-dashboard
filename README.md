# Swiggy Restaurant Performance Dashboard

## Overview

An interactive Power BI dashboard analyzing Swiggy restaurant performance across major Indian cities.

## Key Insights

- Kolkata has the highest average delivery time at 68 minutes.
- Ahmedabad has the lowest average delivery time at 45 minutes.
- Kolkata has the highest number of restaurants.
- Chennai has the highest average rating at 3.78.

## Tools Used

- Power BI
- DAX
- Power Query
- Excel

## Analysis

The dashboard analyzes restaurant distribution, ratings, delivery time, city-wise performance, and price categories.
